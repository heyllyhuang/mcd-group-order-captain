# 结算单输出模板

Step 5 交付物。目标是**团长复制一下就能甩进微信群**，所以：纯文本、无代码块包裹、对齐全、一眼能看懂。

## 模板（纯文本版，直接发群）

```
🍟 麦麦拼单结算 · 麦当劳XX店
10 月 9 日 · 12 人 · 19 件

──────────────────────
小张   巨无霸套餐(无糖可乐)     ¥31.8
小李   烤鸡沙拉                 ¥21.4
小王   麦辣鸡腿堡 ×2            ¥35.6
老王   板烧套餐 + 大薯          ¥38.0
...
──────────────────────
原价合计   ¥386.0
优惠合计   -¥44.5
实付        ¥341.5   （团长已垫付）
──────────────────────

💰 本次共省 ¥44.5（11.5%）
  · 满减凑单   -¥20.0
  · 第二份半价 -¥12.0
  · 套餐替换   -¥12.5

🏷 本单人设
  碳水战神 · 小张   减肥未遂 · 小李   薅券担当 · 团长

请大家按上方金额转给团长，谢谢配合 🙏
```

## 写法规则

1. **金额右对齐、单位只出现一次**，别写成一堆 `¥` 前后乱飘
2. **昵称左对齐**，长度不齐时用空格补，手机上看才不歪
3. **优惠要拆开写**，只写一个"共省 44.5"没有说服力；写出「怎么省的」才有价值
4. **人设标签最多 3 个**，且只调侃消费内容（碳水战神、无糖选手、加餐狂魔），**不涉及外貌/体重/收入/性别**
5. **结尾给一句可执行的话**（"按金额转给团长"），不要让群友猜
6. 有人**没点**、**待确认**的，在明细里单独一段标出来，不要混在正常行里

## 待确认段（有未表态者时追加）

```
❓ 还没报的：老周、小赵
   我按当季热销给小李推荐了「麦香鱼套餐」，请本人确认
```

## 有凑单加购时追加

```
➕ 团长加购（为凑满减，谁想吃谁认领）
   大薯条 ×2   ¥26.0
```

## 变体：给领导/报销用（正式版）

去掉 emoji 与人设标签，加一行门店与订单号，改成：

```
麦当劳拼单消费明细
门店：麦当劳XX店        订单号：XXXXXXXX
日期：2026-10-09       参与人数：12

序号  姓名    消费内容              金额
1     小张    巨无霸套餐            31.8
...
合计：341.5 元（已优惠 44.5 元）
```

# 模式 B 输出：配餐方案对比

没人愿意报吃什么时，团长自己定的方案。**必须给三档**，不要只给一个"最佳答案"。

```
🍟 团餐配餐方案 · 下午茶 · 12 人
建议份数：主食 12 份 / 小食 8 份 / 饮料 10 份

  省钱版   ¥329.0   人均 27.4   预算紧、只求吃饱
  均衡版   ¥423.0   人均 35.3   通用推荐 ⭐
  体面版   ¥535.5   人均 44.6   请客 / 重要场合

⭐ 推荐：均衡版
💡 小食按人数 70% 配、饮料 80% 配——不是人手一份，这是「不浪费」的关键
```

写法规则：
1. **份数一定写在最上面**，团长最关心的就是「点多少份」
2. 三档都要给**总价 + 人均**，团长看人均才有判断力
3. 结尾点明推荐档位，别让团长自己纠结

# 模式 C 输出：买单策略

回答「怎么买最划算」。核心是让团长看到**拆单前后的差价**。

```
💡 买单策略 · 共 10 份
   可用券：满50减15（每单 1 张）
   配送费：每单 ¥9，满 ¥59 免运

   不拆单      净付 ¥331.0
   拆 5 单     净付 ¥260.0   ← 推荐，省 ¥71.0

⚠️ 拆单前请先确认门店是否接受同址多单，且需分别支付
```

写法规则：
1. **先给结论（拆几单、省多少），再给测算过程**
2. **拆单红线必须一起输出**——不能只报喜不报忧，让团长自己去踩坑
3. 如果拆单反而更贵或没差别，**如实说「建议不拆」**，不要硬推方案凑数
4. 差价很小时（比如省 3 块），提醒「省事也是成本」

# 组合输出：一次完整团餐（推荐用法）

三件事串起来，一次对话交付完整方案：

```
🍟 团餐全案 · 麦当劳XX店 · 12 人 · 下午茶

【一】配餐方案
   建议：主食12 / 小食8 / 饮料10
   均衡版 ¥423.0（人均 35.3）⭐

【二】买单策略
   拆 4 单下单，净付 ¥341.5（比不拆省 ¥81.5）
   ⚠️ 需确认门店接受同址多单

【三】各人应付
   小张 ¥31.8   小李 ¥21.4   小王 ¥35.6  ...
   合计 ¥341.5（已校验 = 整单实付）
```

这个「配餐 → 买单 → 拆账」的三段式，是本 Skill 的完整价值闭环。
